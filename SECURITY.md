# Security policy

Do not disclose vulnerability details in public issues.

Use [GitHub private vulnerability reporting](https://github.com/rstlgu/paranod/security/advisories/new) when it is available. If the repository does not offer private reporting, open an issue requesting a private contact channel without describing the vulnerability.

Include the affected version, deployment configuration, reproduction steps and impact in the private report. Do not include unrelated personal data or production secrets.

Fixes and disclosure should be coordinated with the maintainers before publication.
