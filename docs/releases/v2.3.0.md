# Paranod 2.3.0

Initial release of this clean-history AGPL repository, under GNU AGPLv3 (`AGPL-3.0-only`).

- Graph workspace, builtin plugins, external addons, notes and cases.
- Signed outbound polling for compatible asynchronous addons: local installations need no inbound callback endpoint.
- Graph agent integration with enabled builtin tools, compatible synchronous/asynchronous addons and registered container tools, preserving approval and authorization rules.
- Container runner protocol 2 with cancellable jobs; opt-in agent worker.
- Traefik 3.7.17 with Docker API negotiation.
- Prebuilt Linux amd64 and arm64 images, versioned deployment bundle and checksum-verifying loader.
- Installation, update, backup/restore and complete polling-addon documentation.

The application license changes from the earlier MIT distribution to AGPLv3. The SDK remains MIT. Third-party notices are preserved. The map integration now uses Leaflet directly, replacing dependencies under Hippocratic-2.1. A License & source entry links to the exact release source and license. Previously granted MIT rights are not revoked by this release.

## Downloads

`paranod-deploy-v2.3.0.tar.gz` contains Compose configuration and installation scripts. Follow its README or the [installation guide](https://github.com/rstlgu/paranod/blob/v2.3.0/docs/INSTALL.md).

The loader selects `paranod-images-v2.3.0-linux-amd64.tar.gz` or `paranod-images-v2.3.0-linux-arm64.tar.gz` for the Docker daemon. Images are release archives, not registry tags. `paranod-source-v2.3.0.tar.gz` contains the complete repository source, dependency lockfiles, build scripts and instructions for this release. `SHA256SUMS` covers all bundles. PostgreSQL 16 is pulled separately. Third-party tool/browser images have independent architecture requirements.

Use [Addon SDK 0.5.1](https://github.com/rstlgu/paranod-addon-sdk/releases/tag/v0.5.1) for signed asynchronous polling. The SDK is not needed to run the platform.

## Verification and upgrades

Publication is gated on the repository CI and native Docker fresh-install and backup/restore checks for both architectures. These deterministic checks exercise setup, proxy routing, worker heartbeat, runner protocol and preservation of a synthetic database record, application file and persistent keys. They do not perform an investigation through a real AI provider.

Read the [operations guide](https://github.com/rstlgu/paranod/blob/v2.3.0/docs/OPERATIONS.md) before updating. Back up PostgreSQL, the application volume and configuration together. Keep the Compose project name stable and never point this distribution at another distribution's database without a separately reviewed migration.
