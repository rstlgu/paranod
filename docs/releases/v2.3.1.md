# Paranod 2.3.1

This maintenance release fixes concurrent panel interactions in the graph and flow editors.

- Keep sidebar, Details, Notes and console visibility consistent during rapid toggles and resizing.
- Preserve active-graph controls and floating notes when switching graph tabs.
- Keep floating agent and note windows usable together; release drag state when windows close or reattach.
- Restore console and flow-sidebar opening from resize dividers and prevent duplicate keyboard toggles.
- Keep graph commands reachable in narrow layouts and exclude closed panels from keyboard interaction.

No database schema changes. Back up the database, application data and configuration before updating; retain the same Compose project name and volumes. Follow the [operations guide](https://github.com/rstlgu/paranod/blob/v2.3.1/docs/OPERATIONS.md).

The release includes Linux amd64/arm64 images, a deployment bundle, checksums and the complete corresponding source archive. The application remains AGPL-3.0-only; the separate addon SDK remains MIT.

Validation includes panel regression tests with the real resizing library, production builds, browser checks in Manual, Auto layout, Analysis and Map, flow editor checks, floating windows and narrow layouts. Publication additionally requires repository CI and native Docker fresh-install and backup/restore checks on both architectures. These checks do not invoke an external AI provider.
