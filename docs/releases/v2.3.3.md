# Paranod 2.3.3

Restores panel animations without reverting the concurrent-panel fixes in 2.3.1.

- Graph and flow sidebars, details, notes and console resize together during opening and closing.
- Splitter dragging remains immediate; reduced-motion preferences disable these transitions.
- Docked notes remain visible during closing. Floating agent windows now animate dismissal and stop accepting interaction as soon as they close.

No database schema changes. Follow the [operations guide](https://github.com/rstlgu/paranod/blob/v2.3.3/docs/OPERATIONS.md), retain the same Compose project name and back up the database, application data and configuration before updating.

The release includes prebuilt Linux amd64/arm64 images, the deployment bundle, matching source archive and checksums. The application remains AGPL-3.0-only; the addon SDK is unchanged.

The 2.3.2 candidate was not published. This release includes the corresponding read-only browsing test update and is gated on the complete CI and image verification.
